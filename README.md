# UX Design Role

Created with [Fredrin](https://fredrin.com).

A single-page "About me" for Manoj Salunke, a UX designer, built to support an application
for the [UI/UX Designer role at Fredrin](https://www.fredrin.com/careers/ui-ux-designer).
It covers who I am, what I've done and how to reach me.

## Run

It's plain static HTML/CSS with no build step. Open `index.html` in a browser, or serve it:

    python3 -m http.server 8000

## Publish

`.github/workflows/pages.yml` deploys the repo root to GitHub Pages on every push to `main`.
Enable it once under Settings → Pages → Source: **GitHub Actions**.
